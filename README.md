# ML-Based Short-Horizon Market Prediction & Trading System

A production-oriented machine learning system for predicting short-horizon market movements using market microstructure and order-book features.

## Objectives

- Process high-frequency market data
- Engineer market microstructure features
- Predict short-horizon price movements
- Compare ML models
- Perform leakage-free time-series validation
- Backtest trading strategies
- Incorporate transaction costs and slippage
- Deploy the model as an API
- Track experiments and models
- Monitor model and system performance
